# Blur5 launcher

The source of the `eboot.bin` in Blur5's PS5 app, PPSA11016: built as Blur's own app
(`GAME=PPSA11016`), it shows one page to install Blur from your own copy and set it up, then
hands over to prospero-win's runner, `game.bin`, in the same app folder. Blur's install plan,
`assets/plans/BLUR.json`, is generated by `profile/blur/make-blur-plan.py` in the main repo.

The page is in English. Every sentence it shows still goes through `src/core/i18n.hpp`, which
fills in the `{0}`, `{1}`... parts. The game itself plays in the PS5's language when your copy
has it (`library::apply_system_language`).

Blur5 keeps its files in `/data/Blur5`: the player's game copy in `base`, a save to start from
in `save`, and everything the app writes in `app`.

## Building

The main repo's `tools/build.sh` builds it, in its `game-app` step. The quick host tests here
run with `bash tools/store-test.sh`.
